# PRD — Ricardo Torres Portfolio

## Original problem statement
Premium, editorial, high-credibility UX/UI + digital product design portfolio for Ricardo Andrei Torres Medina (UX/UI Project Lead | Digital Product Designer | AI & Conversational UX, Bogotá). Central idea: "I don't just design screens. I solve product problems." Four signature case studies (Fundación Santa Fe, Telefónica/Movistar, Secretaría Distrital de Salud, Secretaría Distrital de Gobierno) with deep process storytelling; six additional projects as concise cards; no fabricated metrics, clients or outcomes; Figma prototype as source of truth (requires login — not accessible at build time).

## Architecture
- Frontend: React 19 + react-router-dom 7, Tailwind, framer-motion (masked hero reveal, scroll reveals, reading progress), lenis smooth scroll. Light/dark theme toggle.
- Backend: FastAPI + MongoDB (contact messages stored in `contact_messages`). Email notification via Emergent managed Resend proxy — activates automatically once `EMERGENT_EMAIL_KEY` is present in backend/.env (currently NOT provisioned).
- Routes: `/` (homepage: hero, positioning, selected work, additional work, capabilities, approach, experience, about, contact), `/work/:slug` (case study microsites, open in new tab from cards), `/cv` (online CV + PDF download).
- Structured content: `src/data/site.js`, `src/data/flagships.js`, `src/data/additional.js`.
- CV PDF: generated by `/app/scripts/generate_cv.py` → `/app/frontend/public/Ricardo_Torres_UX_UI_Project_Lead_CV.pdf` (replace with Ricardo's real CV file at same path when provided).

## User personas
- Recruiter / Design Manager / Head of Design evaluating seniority fast.
- Product Manager / technology leader assessing process depth and collaboration.
- Ricardo (owner) maintaining content via structured data files.

## Core requirements (static)
- Editorial premium aesthetic (Space Grotesk / Inter / JetBrains Mono, off-white/graphite, #E63946 accent), generous whitespace, asymmetric grids.
- Signature case studies: cover, snapshot, context/problem, discovery, research, synthesis, IA, wireframes, interaction, UI, design system, validation, iteration, impact, contribution (mine vs team), learnings, prev/next navigation.
- Additional work: 6 concise cards with light case pages.
- Global actions: Download CV, LinkedIn. Contact form + mailto/tel.
- SEO: title, meta description, Open Graph, Person JSON-LD.
- Content integrity: qualitative, labeled interpretations only — no invented stats.
